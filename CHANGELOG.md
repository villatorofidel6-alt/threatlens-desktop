# Changelog

## [0.1.0] - 2026-08-20

ThreatLens Desktop launches as a local-first defensive static analysis tool. The first release includes file metadata and hashing, entropy and string extraction, explainable threat indicators, bundled local YARA rules, passive bounded URL inspection, static PE/ELF/ZIP/PDF inspection, risk scoring, local SQLite history, CLI/Tkinter workflows, and JSON/HTML/text export.

The release intentionally excludes dynamic execution, browser automation, automatic extraction, password recovery, decryption, exploitation, persistence, and defensive-evasion features.
